## 🚀 Features
- **Mobile-First Responsive Layout**: Built with React 19, TypeScript, Vite, and Tailwind CSS v4.
- **Direct WhatsApp Move Estimator**: High-converting move calculation with instant formatted WhatsApp quotation.
- **Authentic Indian Relocation Imagery**: Real photographic visuals for household shifting, corporate moves, fragile kitchen crockery packing, local colony shifts, NH-16 highway container haulage, and motorbike transport.
- **Real Operational Video Proof**: Integrated 4 live client relocation videos (`office.mp4`, `packing1.mp4`, `packing2.mp4`, `packing3.mp4`) with an interactive lightbox player.
- **Vercel SPA Deployment**: Full `vercel.json` routing rewrites, video streaming MIME headers, and caching.
- **Technical SEO**: Valid UTF-8 XML sitemap (`/sitemap.xml`), `robots.txt`, dynamic canonical meta tags, and JSON-LD schema.
